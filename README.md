# MQTD — Métodos Quantitativos para Tomada de Decisão

Estudos de caso desenvolvidos na disciplina de Métodos Quantitativos para Tomada de Decisão (Ciências Econômicas — UDF), com análise de dados públicos em R e Excel.

## Estudos de caso

### Estudo de caso 1
Tratamento inicial de base de dados bruta em Excel, com organização e preparação para análise.

### Estudo de caso 2 — Ensino Superior Completo por UF
Análise descritiva do percentual de pessoas com ensino superior completo por Unidade da Federação, com dados do Censo 2022 (IBGE).

- Filtragem e organização da base por nível geográfico (UF, região, Brasil).
- Comparações de desvio de cada UF em relação à média nacional.
- Gráficos gerados em R (ggplot2) e em Excel.
- Recorte adicional para o Ensino Superior nos municípios de São Paulo.

**Pacotes usados:** `readxl`, `dplyr`, `ggplot2`, `scales`, `forcats`

Como rodar: abrir o script em `Estudo de caso 2/Script/`, instalar os pacotes indicados no cabeçalho e definir o caminho do arquivo de dados na variável `caminho`.

### Estudo de caso 3
Cálculos e relatório final consolidando os resultados da disciplina.

## Estrutura de pastas

Cada estudo de caso reúne, em uma pasta própria: o(s) dataset(s) utilizado(s) (bruto e/ou tratado), o(s) script(s) em R, os gráficos gerados e o relatório final em PDF.
